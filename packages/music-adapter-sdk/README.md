# 音乐适配器后端契约

`nons-music-adapter-sdk` 提供共享的来源与曲目、能力、业务与账号请求、错误、取消、分页、资源和后端 trait。宿主和默认网易云包使用同一组类型，宿主 `music` 模块只重新导出契约。

`ProviderAccounts` 是宿主为受信任原生后端绑定的单来源桥，提供当前会话、受限凭据读取和账号失效通知；不暴露存储或其他来源的账号管理。它与 `AccountAccess` 一样不是普通功能插件的公开权限。实现方每次读取必须复核来源、账号和实例代次，并将持久凭据处理放在有界阻塞任务中。

`legacy` 与 `migration` 仅保留历史 Track/Lyrics DTO 和纯曲目转换，供已存在的数据与兼容接口使用；新的音乐调用使用不透明 `EntityRef`，不要把数字 ID 或本地路径加入公共曲目。队列事务、系统凭据迁移与账号选择由宿主管理。

共享契约没有平台 SDK、播放引擎、Tauri、账号存储或插件管理器依赖。契约版本保持 `1`。详细接口及预算见 [音乐适配器文档](../../docs/music-adapters.md)。
