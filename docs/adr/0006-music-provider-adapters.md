# 所有在线音乐来源通过统一适配器接入

状态：已接受；阶段一已完成（契约与迁移规则），阶段二至五待实施。日期：2026-10-10。

本决策替代 [ADR 0001](0001-playback-boundary.md) 中允许网易云直接耦合、等待启动多来源框架化的阶段性约定，以及 [ADR 0005](0005-plugin-capability-boundary.md) 中暂不建立多来源框架的限制；独立播放核心、受控宿主能力和前端信任边界继续有效。当前代码和已开放接口仍以 [插件开发与使用](../plugins.md) 与 [实现记录](../implementation.md) 为准，本文不表示迁移已经完成。

## 背景与决定

项目进入多流媒体来源框架化阶段。网易云原生支持是过渡实现，最终与其他在线音乐平台一样作为音乐适配器接入。网易云继续随安装包提供，先在宿主内实现统一适配器接口，后续迁为独立适配器包；随包分发只影响安装与初始化，不赋予独立的业务调用路径。

宿主页面、功能插件和播放资源解析通过统一音乐服务与适配器管理器访问来源。迁移完成后，宿主通用业务不再直接依赖网易云客户端、平台响应或专用 ID 类型。内置和外部适配器遵守相同的公开契约、能力声明、错误、取消、缓存与生命周期规则；运行位置可以不同，契约测试共用。

## 管理归属

音乐适配器是插件的一种，提供音乐来源能力；功能插件提供工具、业务流程或界面扩展。新增独立的适配器管理器（`AdapterManager`），负责适配器发现、安装、加载、启停、版本兼容、能力注册和故障处理，并提供独立管理入口。现有插件管理器（`PluginManager`）继续管理功能插件，适配器不进入其运行注册表，也不由它加载后再转交。网易云从内置阶段起也由适配器管理器管理。

两类管理器可复用包校验、授权、配置、存储和后端执行等基础设施，但各自持有注册表、运行状态和生命周期。基础设施复用不等于统一管理。账号管理器与适配器管理器分别管理账号数据和适配器运行状态，通过绑定来源与账号的上下文协作。

## 职责与接口

音乐适配器提供平台能力供宿主调用，功能插件调用宿主能力实现工具或界面扩展，两类契约分别定义。灵动岛、下载和转换工具不因引入适配器而接管播放核心。

宿主负责统一音乐界面、查询调度、混合队列、音频读取与解码、缓冲和无缝预加载、输出设备、系统媒体控制、缓存预算及受控系统能力。适配器负责平台协议、登录协议、响应转换、平台业务规则和播放资源解析。平台专有能力通过可选扩展表达，不将其加入所有来源的必选接口。

基础契约包含来源描述、曲目读取和播放资源解析。搜索、内容浏览、账号、用户曲库、收藏与歌单写入、推荐、私人 FM、歌词和下载按能力组声明，按实际需求逐步实现。宿主同时区分适配器支持的能力与当前账号、曲目实际允许的操作，提供不可用原因，避免把试听资源当作完整播放资源。

公共契约遵循以下语义：

- 曲目、歌单、专辑和艺术家引用包含稳定来源标识与不透明字符串 ID；账号相关操作另带会话上下文。相同平台 ID、相同歌名或歌词匹配不改变曲目来源，跨平台匹配另存关联。
- 分页使用不透明游标，由适配器转换为平台页码、offset 或 token。结果和请求均设数量、大小与时间上限。
- 播放资源描述包含实际音质、试听限制、有效期与访问方式。宿主校验后建立受控资源句柄，带凭据的 URL 和请求头只在内部消费，不交付普通插件、写入日志或持久化队列。过期资源重新解析，预加载结果同时检查播放、账号和适配器代次。
- 账号获取、凭证格式和平台登录协议由适配器定义，持久凭证由账号管理器统一保存，具体职责和信任边界见下节。普通功能插件通过业务接口查询、收藏和播放；现有显式授权的 `account:credentials` 作为敏感兼容能力保留，不作为通用音乐接口的前提。
- 宿主统一控制缓存容量、淘汰、请求合并和失效，适配器提供缓存建议及写操作影响范围。缓存键区分来源、账号范围、操作和参数；账号切换及写操作不能复用旧结果。
- 错误区分未登录、资源不存在、权限不足、地区限制、限流、网络失败和能力不支持；平台原始信息仅作为经过敏感数据过滤的诊断补充。

## 账号管理与凭证边界

适配器完整负责平台特有的账号获取方式和登录流程，包括二维码、密码、浏览器授权等实际采用的方式，以及凭证解析、校验、刷新和失效判断。账号管理器不规定平台的登录步骤、成功条件或凭证字段，也不实现平台刷新协议。宿主可以提供登录界面容器，内容和交互由适配器决定。

账号管理器统一管理账号记录、当前账号选择、凭证持久化和状态通知，按来源与账号隔离。凭证是适配器定义的不透明数据，不预设为 Cookie、Token 或固定结构。适配器完成登录后交付账号信息与凭证；运行时通过绑定来源、账号和加载实例的接口获取必要凭证，完成刷新后更新统一存储。账号管理器负责存储、访问控制与会话代次，适配器负责平台语义。

停用适配器、切换账号、退出登录和删除保存账号是独立操作。停用撤销运行实例访问，不自动退出平台账号或删除持久凭证；平台退出请求由适配器执行，本地凭证清理由账号管理器负责。账号删除或退出时使旧请求失效，远端退出失败与本地清理结果分别报告。

凭证统一持久化是适配器的强制契约：普通配置、业务存储、独立 secrets 分区、授权文件和浏览器存储均不得用于另存平台凭证。宿主执行最小权限，默认提供账号专用接口，仅按业务需要开放普通存储；文件访问和任意域名网络权限另行授权。功能插件默认不获得原始凭证，适配器也不能读取其他来源的账号凭证。持久凭证处理尽量留在后端，前端只消费登录展示和交互所需数据。

该契约不等于防恶意适配器沙箱。实现登录和刷新通常要求适配器接触原始凭证；同时具备原始凭证读取和通用写入或网络权限的代码，可能复制、编码后保存或外发凭证，宿主不能可靠依靠内容检测阻止。共享 WebView 的前端尤其不能靠 SDK 权限形成强隔离，继续遵循 ADR 0003 的信任要求。能够适用的请求可使用宿主凭证注入，但不强制所有平台使用同一种认证方式。

凭证访问依靠受控后端、来源与账号范围、实例代次和最小权限限制；接触原始凭证的适配器仍须受信任。账号管理器保证自己管理的存储与访问生命周期，不保证删除适配器私自复制或外发的数据，也不作为阻止凭证泄露的完整安全边界。

## 执行与生命周期

账号处理和播放资源解析在独立于前端页面的后端执行，WebView 隐藏、释放或插件页面卸载不影响来源继续服务。沿用 [ADR 0003](0003-runtime-plugins.md) 的受控后端方向；适配器不在音频线程执行。接入外部适配器前，重新核对 HTTP 响应上限、调用期限与并发预算，并为关键播放解析保留调度能力，避免普通查询阻塞首声或预加载。预算有界，性能结论需实测。

停用或卸载适配器时拒绝新请求，取消其未完成查询和预加载，撤销账号与资源访问能力。已交付播放核心且无需继续访问适配器的资源可以播放到结束；依赖已撤销访问能力的资源报告来源不可用。队列保留曲目引用并标记不可用，恢复来源后可重新解析，不直接删除用户队列。账号切换、重载后的旧结果不能覆盖新状态。

本地音乐复用统一曲目模型和通用查询体验，目录监听、索引及文件权限仍由宿主管理，无需套用在线登录协议。歌词来源独立于音频来源，继续由统一歌词服务安排来源顺序、匹配、缓存和回退。

## 取舍与迁移

继续扩展网易云专用接口成本较低，但会让第二个平台和后续网易云拆分承担重复迁移。直接将网易云整个实现搬进现有前端插件，则无法保证 WebView 释放后的账号与播放资源解析。采用统一契约、先内置后拆包的路线，增加接口和数据迁移成本，以换取宿主与平台实现可独立演进。

迁移按以下顺序推进，每阶段保持已有播放与本地音乐行为可用：

1. 确定统一标识、能力组、错误、会话与资源契约，划分独立适配器管理器、账号管理器与现有插件管理器的职责，以及历史曲目、队列和账号数据的迁移规则。
2. 在适配器管理器中注册内置网易云适配器，迁移单曲读取与播放资源解析；通用调用方只依赖统一接口。
3. 迁移搜索、内容详情、账号、用户曲库和写操作，功能插件逐步改用统一音乐客户端。现有 `netease.*` 仅保留为有迁移说明的兼容入口，不再承担新的通用能力。
4. 使用测试适配器覆盖非数字 ID、不同分页、缺少能力、账号切换、过期资源及停用，再接入一个外部适配器验证契约和运行预算。
5. 将网易云迁为默认随包提供的独立适配器，保持来源标识、已有数据及宿主调用契约稳定；完成后移除迁移期直连路径。

阶段一已确定内部方法名、DTO、契约版本和初始数据上限，见下节；外部 ABI 与运行预算仍在对应接线阶段确定。本决策不要求一次开放全部能力，也不承诺所有平台具有相同功能。验收覆盖适配器与功能插件管理隔离、不同登录流程、不透明凭证存储及越权拒绝、停用不删除账号、账号退出与删除的清理、适配器契约、混合队列、会话隔离、缓存失效、WebView 释放后的播放、停用与重载，以及既有播放和跨平台检查；受控接口测试通过不代表已能阻止恶意代码外发凭证。

## 阶段一完成记录（2026-10-10）

统一契约版本 1 与只读历史数据转换已在 `app/src-tauri/src/music/` 落地。稳定来源、不透明字符串 ID、能力组与当前操作限制、公共错误、账号/实例/播放代次、取消/期限、游标分页、缓存作用域、实际音质/试听/有效期、受控资源句柄和后端不透明凭据分别定义；基础适配器接口为来源描述、单曲读取和播放资源解析。历史在线 ID、本地路径哈希及歌词关联、混合队列、账号 profile 的转换有契约测试。

三个管理器分别拥有运行注册表、账号存储/选择和功能插件生命周期；职责、系统凭据跨存储迁移的恢复规则及后续注意事项见 [音乐适配器契约与迁移记录](../music-adapters.md)。阶段一不接入运行时，不修改现有数据库或系统凭据，也不将新契约开放为功能插件接口。AdapterManager、AccountManager、统一调用方和实际持久化迁移按阶段二、三接入，外部 ABI 按阶段四验证；这些尚未实现的能力不计入阶段一完成范围。验证环境和结果见 [实现记录](../implementation.md)。
