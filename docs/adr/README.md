# 架构决策与有效约定

这里保存已接受且仍有效的架构决策。项目整体范围见 [项目约束](../architecture.md)，接口细节见对应开发文档，依赖版本与验证记录以实际配置和 [实现记录](../implementation.md) 为准。

| 决策                                                       | 保留的约定                                                                               |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [0001：播放核心边界](0001-playback-boundary.md)            | 网易云优先；本地与在线共用独立播放核心；多来源框架化由用户明确启动。                     |
| [0002：缓存与本地目录](0002-runtime-and-ttml-cache.md)     | 运行时查询有界并统一失效；磁盘资源缓存仅保存 TTML；目录扫描按来源对账，保留原始文件。    |
| [0003：插件运行与前端信任边界](0003-runtime-plugins.md)    | Component Model 后端受限执行；React 前端共用主 WebView，必须信任；插件复用独立播放核心。 |
| [0004：配置、页面与文件权限](0004-plugin-configuration.md) | 配置保存与呈现独立；修订冲突不覆盖；数据目录分离；外部目录显式授权，卸载不删除外部文件。 |
| [0005：宿主与插件职责](0005-plugin-capability-boundary.md) | 宿主提供受控系统能力与明确来源的播放器能力；插件实现第三方业务；权限和生命周期统一检查。 |

当前五项决策均有效。已移除固定依赖版本、重复实现细节及一次性迁移叙述，不将已完成的开发步骤保留为后续约束。后续改变决策时明确标注被替代的记录，避免并列保留互相矛盾的约定。
