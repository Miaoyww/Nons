# 宿主提供受控能力，插件组合能力实现业务

宿主原先识别网易云剪贴板链接并解析官方短链，导致插件业务规则进入通用插件运行环境。用户决定将 SDK 分为通用能力与播放器领域能力：前者提供剪贴板、HTTP、文件、存储、配置和事件；后者复用播放器的歌曲查询、播放状态、队列操作和界面组件。插件负责内容识别、第三方协议解析、业务流程及呈现策略。

系统操作由宿主代理。每项能力使用明确类型的调用或订阅接口，共用插件身份、权限范围、加载代次、取消和资源预算检查；网络域名、外部目录及读写范围由授权决定。新增能力只覆盖已存在的需求；仅因某个插件需要而增加平台域名、URL 格式或跳转策略时，将这些规则归入该插件。

网易云查询继续使用宿主既有 Client、账号状态和缓存，通过明确来源的领域接口暴露；这不启动多来源框架。通用 HTTP 不携带宿主账号凭据、不自动跳转，插件决定下一次请求，宿主再次验证授权范围。剪贴板授权描述实际收到的文本能力，旧音乐链接权限不能升级为原文权限。

扩展或迁移能力时，完成标准为：插件业务规则归入插件目录；公开类型、宿主实现、授权展示及生命周期约束一致；测试覆盖未授权访问、范围越界、业务解析和停用后的失效。能力层次不改变 ADR 0003 的隔离边界：WASM 受限，React 前端仍为同一 WebView 中的受信任代码。
