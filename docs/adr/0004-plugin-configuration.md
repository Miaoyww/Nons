# 插件配置、编辑页面与文件权限分别声明

配置管理器负责默认值、校验、持久化、修订冲突和通知；页面负责呈现。两者独立：统一页面由宿主生成，自定义页面由插件注册；自定义页面可以使用配置管理器，也可以仅申请文件权限维护自己的数据。

Manifest 的可选 `configuration` 指向包内 JSON 定义。字段使用 JSON Schema 2020-12；复用 Rust jsonschema，安装和加载时编译规则，禁止外部引用与远程获取。顶层字段键是字面键，不解释点分路径。保存通过 SQLite 修订事务，冲突不覆盖新值。无效旧值保留在原始存储中，读取回退默认值并提供诊断，用户可恢复默认值清理。

自定义页面在设置对话框内使用独立插件导航，避免改变播放器主页面。停用插件仍可编辑统一配置；自定义代码需要加载后执行。`apply: reload` 与加载时快照比较，宿主提示重载，插件负责按声明的生效方式消费数据。

持久数据目录与安装目录分离。文件 API 采用 cap-std 的目录能力与相对路径，外部目录必须由宿主原生选择器授权。文件句柄绑定插件、加载代次和根授权，停用或撤销后关闭。WASM 不开放通用 WASI。相同 WebView 内的受信任前端仍不是安全沙箱，延续 ADR 0003 的边界。

卸载默认清理配置、键值存储和专属数据目录；用户可选择保留。无论是否保留，外部目录授权均撤销，外部文件不删除。具体接口和限制见 [插件配置开发](../plugin-configuration.md)。
