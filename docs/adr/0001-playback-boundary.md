# 网易云优先，播放核心由在线与本地音乐共用

状态：部分被 [ADR 0006](0006-music-provider-adapters.md) 替代。以下保留首阶段背景；网易云直连与多来源框架化的阶段性约定已结束，本地与在线共用独立播放核心的决定继续有效。

当前优先完成网易云音乐，允许网易云业务直接耦合，以控制开发周期；多来源业务框架化在用户明确启动下一阶段后进行。

本地音乐也是当前需求，在线与本地资源共用独立播放核心，统一播放队列与音频行为。当前只设计实际需要的播放资源结构；提前引入来源抽象时，须说明对当前需求的收益与代价。

完整范围与验收约束见 [项目约束](../architecture.md)，当前实现见 [实现记录](../implementation.md)。
