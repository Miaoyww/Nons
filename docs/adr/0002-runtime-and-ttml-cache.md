# 统一运行时缓存，TTML 使用独立磁盘缓存

状态：已接受。

为减少重复查询而不混淆资源缓存与用户数据，前端查询复用统一运行时入口，容量与有效期有界，并合并同键请求。写操作按影响范围失效，账号切换清空相关查询；播放控制、会话与权限检查保持实时执行。

歌词服务负责来源选择、缺失判断与后台更新。当前磁盘资源缓存只保存有效 TTML，不缓存歌曲音频；缓存目录和索引独立于曲库、原始文件及插件数据。清空、设置变更与刷新推进请求代次，旧请求不得重新填充已失效缓存。

本地目录通过变化监听与完整扫描维护索引，导入来源和曲目分开保存，以支持重叠目录和单独打开文件共存。仅在扫描成功后按来源对账，不因目录不可访问而删除此前索引；移除目录不删除原始音乐文件。

具体接入、存储结构、有效期与容量限制见 [缓存与本地音乐](../cache-and-local.md)，验证记录见 [实现记录](../implementation.md)。
